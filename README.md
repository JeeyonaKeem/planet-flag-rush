# PLANET FLAG RUSH

React + TypeScript + Vite + Three.js / Node.js + Socket.IO 기반 2–6인 실시간 게임.

## 실행
Node.js 22.12 이상을 설치한 뒤 이 폴더에서:

```sh
npm ci
npm run build
npm start
```

브라우저에서 http://localhost:3001 접속. 두 개의 **독립 탭**에서 각각 닉네임을 입력합니다. 첫 탭에서 방 생성 → 둘째 탭에서 방 코드 참가 → 방장이 출발하기. 탭 복제는 sessionStorage를 복사할 수 있으므로 새 탭에 주소를 직접 입력하거나 시크릿 창을 사용하세요.

같은 Wi-Fi의 휴대폰: `http://컴퓨터의내부IP:3001`로 접속합니다. 컴퓨터 방화벽에서 해당 포트를 허용해야 합니다. 초대 링크는 현재 접속 주소를 사용하므로 휴대폰 공유 시 localhost 대신 내부 IP 주소로 PC에서도 먼저 접속하세요. 클립보드는 HTTPS/localhost에서 지원되며, 지원하지 않으면 복사할 주소가 표시됩니다.

개발 모드:
```sh
npm run dev
```
Vite http://localhost:5173 에서 API/WebSocket을 3001 서버로 프록시합니다.

검증:
```sh
npm test
npm run build
```

## 구조
- `shared/game.ts`: 반지름·속도·회전·거리·인원 설정, 타입, 구면 이동, 라운드 순서
- `server/engine.ts`: 서버 권한 획득, 적응형 생성, 12개 라운드, 피버·스페셜
- `server/index.ts`: 방 코드, 호스트, Socket.IO, 재접속 토큰, 정리, 정적 파일 제공
- `client/scene.ts`: 구형 행성, 접선 정렬, 추적 카메라, 캐릭터/깃발 애니메이션
- `client/main.tsx`: 대기실·게임 HUD·결과·조이스틱·키보드·마우스·오디오
- `tests/`: 수학/게임 규칙 테스트와 실제 서버 + 독립 Socket.IO 클라이언트 통합 테스트
- `dist/`: 검증한 프런트엔드 빌드

## 게임 규칙
9 × 15초 일반 + 2 × 8초 피버 + 1 × 8초 스페셜 = 159초.
피버는 4·10라운드, 스페셜은 8라운드에 내부적으로 편성되어 있으나 UI에서 사전 예고하지 않습니다.
목표는 해당 시점의 남은 깃발 중 이전 색상과 다른 색상에서 선택합니다.
일반 +1, 피버 +2(70%) / +3(30%), 스페셜 +5. 스페셜에는 황금 깃발만 획득 가능합니다.
깃발은 최초 10개, 일반 미획득 상한 20개. 스페셜 이벤트 동안 별도의 황금 2개가 추가됩니다.
30초 획득 수에 따라 12/8/5/3초 생성. 피버는 간격을 1.5로 나눕니다.
상한에서 목표 깃발이 완전히 사라지면 오래된 비목표 깃발 하나를 교체해 굶주림을 방지합니다.
서버 30Hz 이동·충돌 판정, 15Hz 상태 전송. 클라이언트는 방향 입력만 전송합니다.
재접속은 탭의 sessionStorage 토큰으로 30초까지 유지. 단절 중 캐릭터는 직진하지만 점수를 얻지 않습니다.
방장이 30초 이상 이탈하면 연결된 다음 참가자가 방장이 됩니다. 방 인원이 모두 사라지면 방을 정리합니다.

## 검증 결과
- TypeScript 정적 검사와 Vite 프로덕션 빌드 통과.
- 자동 테스트 5개 통과: 30,000틱 구면 이동/속도/접선 유지, 단일 획득/잘못된 색상 무시,
  12라운드 및 이벤트 종료, 적응형 생성·상한·생성 거리, 실제 2클라이언트 동기화·재접속.
- 브라우저 자동화 도구가 제공되지 않아 실제 렌더링, 터치 기기, 다중 브라우저 화면 QA는 미실시.

## 구현과 남은 검증
구형 자동 이동, 제한된 뒤따르기 카메라, 조이스틱/A·D/마우스, 닉네임, 실시간 순위,
깃발 색상+기호, 획득 파티클, 합성 효과음, 피버 불꽃, 황금 이벤트, 결과/재시작 구현.
실제 별도 서버를 이용하며 봇이나 로컬 멀티플레이 대체물이 아닙니다.

다음은 아직 완성형 품질로 검증되지 않았습니다:
- 휴대폰 실기기 프레임률, 카메라 멀미, 네트워크 지터/고지연 환경. 보간은 있지만 로컬 예측·입력 재조정은 없음.
- 지형은 정확한 구면 + 작은 비충돌 바위·풀입니다. 실제 높이 변화 언덕은 미구현.
- 피버 불꽃은 절차적 저비용 메시이며 고급 불꽃 셰이더가 아닙니다.
- 반지름 40/최초 깃발 10개 조건에서 발견 빈도와 8초 스페셜의 획득 가능성은 사람 플레이 테스트 필요.
- 매치메이킹, 계정, 영구 전적, 다중 서버, 운영 수준 속도 제한/부하 검증 미구현.

## 인터넷 배포
공개 서버 배포는 수행하지 않았습니다. 이 서버는 지속 실행 Node.js 환경이 필요합니다.
`npm ci && npm run build` 후 `npm start`, PORT 기본값 3001.
리버스 프록시는 WebSocket 업그레이드를 허용하고 HTTPS를 적용해야 합니다.
서버 하나에 모든 방이 메모리로 유지되므로 재시작 시 방이 사라집니다. 여러 인스턴스에 분산하면 안 됩니다.
Sites의 Cloudflare Worker 호스팅에는 이 Node.js 서버를 그대로 올릴 수 없습니다.
